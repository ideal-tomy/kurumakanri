# Release Notes — v1.0.0

公開日: （記入）

## 概要

Shaken Notify の初期リリース。車検期限・オイル交換目安の抽出リストと LINE / メールへの **手動送信**、自動見積生成、配信ログ／再送、顧客向け簡易ページを提供します。

## 追加機能

- Supabase Auth + RBAC（ADMIN / STAFF）
- 顧客・車両 CRUD（月平均走行 km・オイル間隔）
- 抽出ビュー: `v_targets_shaken_180` / `v_targets_shaken_90` / `v_targets_oil`
- 通知送信 API（冪等キー・監査ログ）
- LINE Webhook（follow/unfollow/message のログ記録）
- メール送信（Resend + bounce webhook stub）
- 配信停止ページ `/u/:token`
- Edge Function `daily-extract`（`AUTO_SEND_ENABLED=false` が既定）

## 既知の制限事項

- LINE userId と顧客の自動突合せは最小実装（未マッチは監査ログのみ）。
- メール webhook は Resend 形式を想定。プロバイダ変更時は Route Handler を調整してください。
- Playwright E2E はログイン認証が必要なケースを除くスケルトンのみ。

## アップグレード手順

1. `supabase db push`（または Dashboard で migrations 適用）
2. `.env` を本番値に更新
3. `npm run build && npm run start`（または Vercel へデプロイ）
4. `docs/acceptance-checklist.md` に沿って受入テスト

## セキュリティ

- `SUPABASE_SERVICE_ROLE_KEY` と LINE / メール API キーをソースコードにコミットしないでください。
- `OPT_OUT_SECRET` は十分な長さのランダム文字列を設定してください。

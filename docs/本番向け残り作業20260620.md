## 開発側が行う作業

クライアント作業の成果を受けて、システム・インフラ・データを本番状態に仕上げる項目です。  
**上記クライアント作業の実施・情報提供も、開発側が支援・代行する場合はこちらに含めて進めます。**

### 1. Vercel 環境変数（本番）

Vercel → Project → **Settings → Environment Variables → Production** に設定し、**Redeploy** する。

| 変数名 | 必須 | 内容 |
| --- | --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | ○ | Supabase プロジェクト URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ○ | 公開 anon / publishable キー |
| `SUPABASE_SERVICE_ROLE_KEY` | ○ | サーバー専用（漏洩厳禁） |
| `NEXT_PUBLIC_SITE_URL` | ○ | `https://kurumakanri.vercel.app`（独自ドメイン時はそれに合わせる。**末尾 `/` なし**） |
| `LINE_CHANNEL_ACCESS_TOKEN` | ○ | クライアント本番 LINE チャネルのトークン |
| `LINE_CHANNEL_SECRET` | ○ | Webhook 署名検証用 |
| `OPT_OUT_SECRET` | ○ | 配信停止リンク用（本番用ランダム文字列。**仮値のままにしない**） |
| `QUOTE_SHARE_SECRET` | ○ | 見積詳細 `/q/...` 用 |
| `CUSTOMER_PORTAL_SECRET` | ○ | 顧客ポータル `/p/...` 用 |
| `NEXT_PUBLIC_ISSUER_JSON` | 推奨 | 見積書・ポータルの店舗情報（JSON 1 行） |
| `NEXT_PUBLIC_OPS_MANAGER_CONTACT` | 推奨 | 障害時表示用連絡先 |
| `RESEND_API_KEY` | メール時 | Resend API キー |
| `MAIL_FROM` | メール時 | 送信元アドレス |
| `AUTO_SEND_ENABLED` | ○ | **`false` のまま**（自動送信は運用慣れ後） |
| `NOTIFICATION_IDEMPOTENCY_DISABLED` | × | **本番前に削除または `false`**（同日再送防止を有効化） |

参照: [.env.example](../.env.example)

## 本番 GO 判定チェックリスト

- [ ] Vercel 本番環境変数が [.env.example](../.env.example) どおり揃っている

- [ ] 同日同ルールの再送がブロックされる（冪等キー）

- [ ] 法定費用・整備単価が店舗の実態に近い
- [ ] デモデータが整理されている

## よくあるつまずき

| 症状 | 確認ポイント |
| --- | --- |
| LINE 本文が `localhost` | Vercel の `NEXT_PUBLIC_SITE_URL` + Redeploy |
| 「送信しました」だが LINE が来ない | 同日再送（冪等キー）。`results[].message` を確認 |
| 本番だけ LINE 失敗 | `LINE_CHANNEL_ACCESS_TOKEN` が Vercel に未設定 |
| リンクが `/me?cid=` のまま | `CUSTOMER_PORTAL_SECRET` / `QUOTE_SHARE_SECRET` 未設定 |
| デモ顧客に送れない | `line_user_id` 未登録・LINE 未友だち追加 |

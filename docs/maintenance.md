# 保守・コンサル契約における対応範囲（案）

> 実際の契約書と矛盾する場合は **契約書が優先** されます。ここではヒアリング済みの「初期10万円 + 月10万×12か月」を前提にした目安です。

## 含む（標準）

| 区分 | 内容 |
| --- | --- |
| バグ修正 | 本システムの不具合修正 |
| 軽微改善 | UI の文言変更・並び順・フィルタ追加など小さめのUX改善 |
| インフラ支援 | Supabase / Vercel / LINE / メール DNS の設定質問への回答 |
| 運用コンサル | 通知運用フローの提案・チェックリスト更新 |
| セキュリティパッチ | Next.js / Supabase Client の依存ライブラリ更新（互換範囲） |

## 単純作業だが事前合意が望ましいもの

| 区分 | 内容 |

| 請求・決済連携 | 外部決済・インボイス対応など |

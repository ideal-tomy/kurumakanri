# アカウント準備チェックリスト（クライアント側）

> 1ページ印刷可。本番稼働までに、貴社で以下のアカウント・契約をご準備ください。
> ■ 印 = クライアント（御社）／ ▲ 印 = ベンダー（弊社）作業

## 運用用メールアドレス（最初に決める）

本システムを **御社名義でデプロイし運用する** 場合、次の方針を推奨します。

- **専用メールを1つ**（例: Gmail、または `ops@御社ドメイン`・グループウェアの共有アドレス）を用意し、**Supabase / Vercel / メール送信サービス（Resend 等）などのクラウド登録** にそのアドレスを使う。
- 同一アドレスに集約する理由: **請求・セキュリティ警告・パスワードリカバリ** の見落とし防止、担当者交代時の **権限・契約の引き継ぎ** がしやすい。
- **個人の私用メールのみ** にしない（退職・異動でアカウント復旧が困難になりやすい）。可能なら **グループメールまたはバックアップ担当が受信できる共有アドレス**。
- **管理画面ログイン（Supabase Auth）** 用のメールは別途、スタッフごとに業務アドレスを発行（本チェックリスト末尾の「初期スタッフアカウント」と別物）。

- メール添付・チャットへの貼り付けは避けてください。

# 障害時エスカレーションフロー

## 基本方針

- まず再送可能かを判断し、再送で復旧しない場合は管理者へ連絡する
- 連絡時は「エラーコード」「対象件数」「実施時刻」を必ず添える

## エラー別対応

### `NO_LINE_USER_ID`

- 意味: 顧客に LINE userId が紐付いていない
- 対応:
  1. 顧客へ友だち追加 / 紐付け案内
  2. 紐付け完了後に再送

### `MISSING_LINE_ACCESS_TOKEN`

- 意味: サーバー環境変数不足
- 対応:
  1. 即時に管理者へ連絡
  2. `LINE_CHANNEL_ACCESS_TOKEN` 設定を確認
  3. 再デプロイ後に再送

### `HTTP_401` / `HTTP_403`

- 意味: LINE API認証または権限問題
- 対応:
  1. 管理者へ連絡
  2. Channel Access Token 再発行/再設定
  3. 小件数で再送テスト後に本再送

### `HTTP_429`

- 意味: レート制限
- 対応:
  1. 5〜10分待機
  2. 分割して再送

### `NETWORK`

- 意味: 一時通信障害
- 対応:
  1. 5分後に再送
  2. 2回失敗したら管理者へ連絡

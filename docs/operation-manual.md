# Shaken Notify 操作マニュアル（スタッフ向け）

> PDF 出力しやすいよう見出し中心で構成しています。
> 「📷」マークは **受入会後に実画面のスクショを差し込む枠** です。

## 1. ログイン / ログアウト

1. ブラウザで管理画面 URL を開く。
2. メールアドレスとパスワードを入力し「ログイン」。
3. 作業終了後は右上「ログアウト」。

📷 **挿絵枠**: `/login` 画面全体

---

## 2. ダッシュボードの見方

- **登録車両数**: DB に登録された車両の台数。
- **90日以内 / 180日以内**: 通知抽出ビューに該当する件数の目安。
- **今月の見積発行**: 当月に `issued_at` が入った見積の件数。
- **期限が近い顧客**: 残日数が短い順に最大 8 件。
- **直近の配信履歴**: 最新の送信ログサマリ。

📷 **挿絵枠**: `/dashboard`

---

## 3. 顧客・車両の登録・編集

### 3.1 新規顧客

1. サイドバー「顧客一覧」→「+ 顧客を追加」。
2. 氏名（必須）・連絡先・備考を入力。
3. 「車両情報も同時に登録」にチェックを入れると、車両タブもまとめて入力可能。
4. **月平均走行 km** はオイル交換目安の推定に利用（未入力だと推定が甘くなる）。
5. 「登録する」→ 詳細ページへ遷移。

📷 **挿絵枠**: `/customers/new`

### 3.2 顧客詳細での編集

- 「顧客情報」「配信同意」「車両」それぞれで「保存」「更新する」を押すと反映。
- 車両が複数ある場合は `<details>` 内から追加。

📷 **挿絵枠**: `/customers/[id]`

---

## 4. 通知対象リストの確認（一覧 + 手動送信）

サイドバー「通知対象リスト」から各画面へ。

| 画面 | 抽出の意味 |
| --- | --- |
| 車検半年前 | 残日数 150〜210 日 |
| 車検3か月前 | 残日数 60〜100 日 |
| オイル交換目安 | 推定走行が「前回オイル + 間隔 −200km」以上 |

### 4.1 個別送信

1. チャネル（LINE / メール / 両方）を選択。
2. 行末「送信」をクリック。
3. 確認ダイアログで OK。

### 4.2 一括送信

1. 左端チェックボックスで対象を選択（ヘッダーで全選択）。
2. 「選択を一括送信」。
3. 確認ダイアログで OK。

> **同日・同一ルール・同一チャネル** への再送は、冪等キーによりブロックされます（誤送信防止）。

📷 **挿絵枠**: `/lists/shaken-180`（他ルールも同様に 1 枚ずつ）

---

## 5. テンプレートとプレビュー

- `/templates` でテンプレ一覧を確認できます（編集 UI は簡易版。大量変更は DB またはバージョン管理で）。
- API `POST /api/notifications/preview` で任意顧客の文面プレビューが可能（管理者向け）。

📷 **挿絵枠**: `/templates`

---

## 6. 自動見積の生成

1. 顧客詳細から該当車両の見積ページへ（リンクあり）。
2. 「+ 自動見積を生成」ボタン。
3. 法定費用（固定）＋標準整備項目＋備考テンプレが反映された見積が作成されます。
4. 実車確認後に追加費用が発生する場合は **備考に明記済みの定型文** をベースに説明してください。

📷 **挿絵枠**: `/quotes/[vehicleId]`

---

## 7. 配信履歴・再送

1. `/notifications/logs` を開く。
2. 状態・チャネル・キーワードで絞り込み。
3. 失敗したジョブにチェックを入れ、「選択を再送」「LINEで再送」「メールで再送」のいずれかを実行。

📷 **挿絵枠**: `/notifications/logs`

---

## 8. 配信停止リンクへの対応

- メール本文の「配信停止」リンクから顧客が停止操作すると、`MAIL` チャネルの同意がオフになります。
- **LINE のブロック / トーク削除** は Webhook で検知される場合がありますが、確実ではありません。不明点はスタッフが詳細画面で確認してください。

📷 **挿絵枠**: `/u/[token]` の確認画面

---

## 9. トラブル時のエスカレーション

| 症状 | まず確認 | 連絡 |
| --- | --- | --- |
| LINE が届かない | `line_user_id` が空でないか | 開発サポート |
| メールが届かない | DNS (SPF/DKIM)、迷惑メールフォルダ | 開発サポート + インフラ担当 |
| ログインできない | `staff_profiles` に自分のユーザがあるか | 管理者ユーザー |

詳細は `docs/faq.md` を参照してください。

## 3. 処置方針

### F-01 ポータルに店舗名を出す

| 項目 | 内容 |
| --- | --- |
| 処置タイプ | コード修正 + 設定（`NEXT_PUBLIC_ISSUER_JSON`） |
| 想定ファイル | `customer-portal-view.tsx`、`globals.css` |
| 処置内容 | ヘッダー付近に `issuer.companyName` を表示。未設定時は非表示（開発メッセージは出さない） |
| 完了の目安 | 第一画面で店名・顧客名・車種が揃って見える |

### F-02 / F-03 タップ領域の引き上げ

| 項目 | 内容 |
| --- | --- |
| 処置タイプ | CSS 調整 |
| 想定ファイル | `globals.css` |
| 処置内容 | モバイル: `.quote-cta-btn` / `.portal-cta` を min-height 44px。`.btn-sm` を 44px または主要操作では `.btn` を使う。`.btn-nav-compact` / `.page-back` を ≥40–44px |
| 完了の目安 | 主要 CTA・戻る・ログアウトが指で押しやすい |

### F-04 見積書スマホの数量・単価

| 項目 | 内容 |
| --- | --- |
| 処置タイプ | CSS 調整 or 仕様合意 |
| 想定ファイル | `globals.css`、必要なら `quote-document.tsx` |
| 処置内容 | **推奨**: スマホでも数量・単価を表示（小さめフォント / 折り返し）。または「詳細は印刷で確認」の短い注記を画面に追加 |
| 完了の目安 | 顧客が画面上で内訳の根拠を追える |

### F-05 発行者 JSON の本番設定

| 項目 | 内容 |
| --- | --- |
| 処置タイプ | 設定（コード変更なし） |
| 想定ファイル | Vercel 環境変数 |
| 処置内容 | `NEXT_PUBLIC_ISSUER_JSON` に店名・電話等を設定し Redeploy。[本番環境構築ガイド.md](./本番環境構築ガイド.md) のチェック項目として実施 |
| 完了の目安 | ポータルに電話 CTA、見積書に発行者情報が載る |

### F-06 プレビュー phone-frame の簡素化

| 項目 | 内容 |
| --- | --- |
| 処置タイプ | コード修正 |
| 想定ファイル | `customer-portal-preview-frame.tsx`、`globals.css` |
| 処置内容 | 送信シート内は phone-frame をやめ、枠なしスクロール（または軽いボーダーのみ）に変更。注記「顧客が見る画面」は残す |
| 完了の目安 | シート内で二重スクロールが解消される |

### F-07 整備費用一覧のサンプル表記

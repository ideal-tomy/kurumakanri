# 週次運用 Runbook

## 運用体制

- 担当者: 1名
- バックアップ: 1名
- 障害時連絡先: 管理者

## 実施タイミング

- 毎週1回（例: 月曜 09:00）

## 週次オペレーション手順

1. `/priorities` を開き、フィルタを `今週の送信候補` にする
2. `今週送信候補` 件数を確認
3. 対象顧客へ連絡（LINE送信 / 電話対応）を実施
4. 手動タスクを `完了` に更新
5. `/notifications/logs` で `FAILED` 件数を確認
6. 失敗分を `LINEで再送` または `メールで再送`
7. 再送でも失敗したものは管理者へ連絡

## 運用ルール

- 対応済み顧客は再送対象に含めない
- `今週完了` にした顧客は優先候補から自動除外される
- 再送前に失敗理由（error）を必ず確認する

## 週次チェック項目（記録用）

- 今週送信候補: __件
- 送信成功: __件
- 送信失敗: __件
- 再送成功: __件
- 管理者エスカレーション: 有 / 無

# FAQ（運用・トラブルシュート）

## LINE

### Q1. メッセージが送信できない（FAILED）

**確認ポイント**

1. `customers.line_user_id` が空になっていないか。
2. Messaging API のチャネルアクセストークンが期限切れでないか。
3. ユーザーが公式アカウントをブロックしていないか。

**運用上のヒント**

- 店頭で QR から友だち追加してもらい、スタッフが管理画面で `line_user_id` を手入力／自動連携ログと突き合わせます。
- Webhook で未マッチの follow が来た場合は `audit_logs.action='line.follow_unmatched'` が残ります。

### Q2. 自動で line_user_id が入らない

現状の実装では **電話番号などとの自動マッチングは行わず**、未マッチは監査ログのみです。
運用で「友だち追加後に顧客IDを伝えてもらう」「スタッフが Developers のログから userId をコピー」などのフローを決めてください。

## メール

### Q3. メールが届かない

1. **DNS**: SPF / DKIM / DMARC が送信サービスのガイド通りか。
2. **迷惑メールフォルダ**: 初期ドメインだと判定されやすいです。
3. **バウンス**: `notification_logs.result='BOUNCED'` が無いか確認。

### Q4. 配信停止したのにまだメールが届く

- 停止リンクは **チャネル単位** です。`/u/:token` が MAIL 宛か確認してください。
- 別のメールアドレスが登録されていないか、`customers.email` を再確認してください。

## データ・計算

### Q5. オイル交換の「推定走行距離」がずれる

月平均 km と前回オイル時の入力精度に依存します。**あくまで目安**であり、本文テンプレにもその前提を書いてください。

### Q6. リストに載っているのに送信できない

- チャネルごとの同意 (`consents.opt_in`) が false になっていませんか。
- LINE の場合は `line_user_id`、MAIL の場合は `email` が空ではありませんか。

---

## ログイン・権限

### Q7. `no-profile` エラーになる

`staff_profiles` に自分の `user_id` が無い、または `active=false` です。管理者に依頼して追加してください。

### Q8. ADMIN と STAFF の違いは？

テンプレートや通知ルールの書き換えは ADMIN のみ、日常送信は STAFF で十分、という分担を推奨します（詳細は `docs/account-roles.md`）。

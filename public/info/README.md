# 整備費用一覧 画像アセット

LINE 通知から案内する公開ページ（`/info/maintenance`, `/info/oil`）で表示する画像をここで管理します。

## ディレクトリと用途

- `public/info/maintenance/` … 車検向けの整備費用一覧。タイヤ・足回り・ライト・バッテリー・オイル等を **すべて含む**。`shaken_180days` / `shaken_90days` の LINE 通知から案内される。
- `public/info/oil/` … オイル交換通知（`oil_4000km`）から案内される。**オイル関連の画像のみ** を置く。

## 表示ロジック

- ページコンポーネント（`src/app/info/maintenance/page.tsx`, `src/app/info/oil/page.tsx`）が **画像ファイル名を配列でハードコード** しています。
- 追加・差し替え後は対応するページの配列 (`IMAGES`) も更新してください。

## ファイル命名

- 形式: `{topic}-{YYYY-MM}.{ext}`（例: `tires-2026-05.svg`）
- 同名で上書きせず **新しいファイル名でアップ → 配列を切り替え** を推奨（LINE 内ブラウザのキャッシュ対策）。

## 画像仕様

- 縦長 or 横長どちらでも可。スマホ縦持ち想定で **横幅 800px 以下** を目安に。
- 視認性のため、画像内に「※あくまで目安価格です」を明記してください。
- アクセシビリティ用に、ページ側で `alt` テキストを必ず設定する。

## 差し替え手順（開発者）

1. このディレクトリに新しいファイルを追加（例: `tires-2026-08.svg`）。
2. 対応するページ（`src/app/info/maintenance/page.tsx` 等）の `IMAGES` 配列を新ファイルに差し替え。
3. 旧ファイルは履歴として **残しても削除しても可**。
4. commit して deploy。

## サンプル画像について

リポジトリには SVG のサンプル画像が含まれています。本番環境では Excel/Numbers 等で作った正式な料金表画像（PNG/JPG）に差し替えてください。
